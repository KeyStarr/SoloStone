# Историческая кампания

![Три классические карты на столе в таверне. Красная дорога на карте ведёт через горы к золотому знамени.](docs/images/banner.jpg)

«Историческая кампания» — рабочее название одиночной офлайн-игры на основе SoloStone. Идея кампании — пройти путь от классического Hearthstone образца 2014 года до первых дополнений, собрав собственную коллекцию и колоды для каждой эпохи.

## Что уже работает

В текущей сборке можно играть рейтинговые матчи против ботов, редактировать колоды, покупать и открывать бустеры, создавать карты за чародейную пыль и распылять лишние экземпляры. Коллекция, золото, пыль и рейтинг сохраняются на компьютере.

Сейчас игра использует фиксированную мету Violet Hold. Движок уже поддерживает многие базовые и классические карты и содержит реализации карт ранних дополнений. Исторический баланс 2014 года ещё предстоит проверить. Стартовая коллекция Classic, подбор соперников по эпохам и переход между ними находятся в планах. [Ревизия кодовой базы и план очистки](docs/CLEANUP_PLAN.md)

## Как будет устроена кампания

Вы начнёте с небольшой коллекции классических карт и сами соберёте первую колоду. За рейтинговые матчи против ботов вы будете получать ресурсы для бустеров и создания карт. Первые соперники будут играть простыми колодами. Примерно с середины пути к Легенде начнут регулярно встречаться полноценные соревновательные колоды той эпохи.

**Достижение Легенды откроет следующую эпоху.** В текущей можно будет оставаться сколько угодно. Когда вы решите перейти дальше, рейтинг сбросится, а коллекция, золото и пыль сохранятся. У каждой эпохи будут свои доступные карты, баланс и колоды соперников.

| Порядок | Эпоха |
| --- | --- |
| 1 | Классический Hearthstone (2014) |
| 2 | Проклятие Наксрамаса |
| 3 | Гоблины и гномы |
| 4 | Чёрная гора |
| 5 | Большой турнир |
| 6 | Лига исследователей |

Позднее могут появиться и другие исторические обновления. Экономику предстоит настроить так, чтобы регулярная игра позволяла улучшать колоду, а выбор карт оставался за игроком. Цены бустеров и размер наград пока открыты.

## Как собрать, установить и запустить

1. Подготовьте 64-разрядную Windows 10 или 11, собственную легально полученную копию Hearthstone и место для второй копии клиента. Интеграция SoloStone проверялась на версии **37.0.0.254477**. [Версия клиента](installer/tested-client.json)
2. Соберите установщик из этого репозитория. Нужны .NET SDK **10.0.402**, библиотеки из вашей установки Hearthstone и файлы загрузчика. Для локальной сборки оставьте ключи подписи обновлений незаданными. По умолчанию установщик появится в `installer/out/SoloStone-Setup-<версия>.exe`. [Инструкция по сборке](docs/BUILDING.md)
3. Установщик пока использует имя, ярлыки и каталог сохранений SoloStone. Если SoloStone уже установлен, используйте отдельную учётную запись Windows для этой сборки, чтобы у каждой установки были свои файлы и сохранения.
4. Закройте Battle.net и его агент обновлений. Запустите собранный установщик, укажите исходную папку Hearthstone и выберите отдельную папку для офлайн-копии. Подтвердите создание правил брандмауэра Windows для этой копии.
5. Перед каждой игрой закройте Battle.net и его агент, запустите ярлык **SoloStone** и нажмите **Play**. Лаунчер проверит версию клиента и его сетевую изоляцию. Сохранения находятся в `%LOCALAPPDATA%\SoloStone\saves`.

Список доступных тестов можно посмотреть командой `python tests/run.py --list` из корня репозитория. [Руководство по тестированию](docs/TESTING.md)
